# CS2FOW 0.3.6

CS2FOW 0.3.6 restores strict compatibility with CS2 build `24537688` (`1.41.7.4`), adds an immediate update-check command, and restores the optional official-map bundle.

## Update from 0.3.5

CS2FOW 0.3.5 can prepare this update automatically. Wait for the update message or run `cs2fow_check_update`, then fully restart the server. The running plugin is never replaced while the server is online.

For a manual update:

1. Stop the server.
2. Save a copy of any customized `game/csgo/cfg/cs2fow.cfg`.
3. Extract the 0.3.6 ZIP for the server's operating system directly into `game/csgo`, replacing the old CS2FOW files.
4. Reapply any custom configuration values and keep `cs2fow_config_loaded` as the final line.
5. Start the server, load a map, and run `cs2fow_status`.

## What changed

- Updated all strict Windows and Linux fingerprints and private addresses moved by the latest CS2 update. Unknown binaries still disable protection safely instead of guessing.
- Added `cs2fow_check_update` to check immediately without waiting for the six-hour timer. It also works when automatic updates are disabled.
- Restored the optional official-map ZIP with 23 freshly baked and validated map pairs from the current CS2 build.
- Valve changed the source geometry for `cs_shelter`, `de_boulder`, `de_cache`, `de_debris`, and `de_fachwerk`; those five maps now have new matching bakes.

Visibility decisions, capsule and AABB probes, smoke and HE behavior, transmit handling, worker settings, and fail-open behavior are unchanged from 0.3.5.

## Official maps

New installations can extract `cs2fow-0.3.6-official-maps.zip` into `game/csgo`. It contains ready-made data under `addons/cs2fow/data/maps`, avoiding the first-load bake for the 23 bundled maps.

Servers that already have old bakes may keep them: CS2FOW validates each map source and automatically rebakes only mismatched files. Installing the new map ZIP simply avoids that wait.

## Confirm that it works

Run:

```text
cs2fow_status
```

After the map is ready, the first line should report `CS2FOW 0.3.6: PROTECTED`. If it reports `UPDATE REQUIRED`, the installed CS2 server binary does not match this release and CS2FOW remains fail-open.

## Release files

- `cs2fow-0.3.6-windows-x86_64.zip` — Windows servers
- `cs2fow-0.3.6-linux-x86_64.zip` — Linux servers
- `cs2fow-0.3.6-official-maps.zip` — optional ready-made official-map data
- `SHA256SUMS.txt` — integrity checksums for all three ZIPs
- `v0.3.6-manifest.json` — verified CS2 build, server fingerprints, map list, and artifact hashes

Compiled packages are distributed only as release assets, never through a direct binary link in the README.
